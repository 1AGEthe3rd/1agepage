# 1AGE Page

**Identity, profiles, messaging, and people discovery for the 1AGE Solana ecosystem.**

1AGE Page is the persistent identity and connection layer across 1AGE.

It is designed to support profiles, people discovery, messaging, and integration with 1AGE World, Exchange, Quest, Games, Space, and Plus.

1AGE Page is not a traditional social media feed. That role belongs to 1AGE Space.

## Development

This repository currently contains a frontend prototype. Production identity, authentication, messaging, and wallet services require secure backend infrastructure.
